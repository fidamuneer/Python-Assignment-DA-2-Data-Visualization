# Python-Assignment-DA-2-Data-Visualization
## About This Project

As part of my Data Analytics learning journey, I worked on this assignment to explore data visualization using Python.

For this project, I used the NYC Taxis Dataset to understand how raw data can be explored, cleaned, analyzed, and presented through different visualizations.

My main focus was to get hands-on experience with Pandas, Matplotlib, and Seaborn and understand how visualizations help us find patterns and insights from data.

## Dataset

- Dataset: NYC Taxis Dataset
- Source: Seaborn built-in dataset
- Records: 6,433
- Columns: 14

The dataset contains information about taxi trips, including distance, fare, tips, pickup time, payment methods, and pickup locations.

## Tools & Libraries

- Python
- Jupyter Notebook
- Pandas
- NumPy
- Matplotlib
- Seaborn

## What I Worked On

### 1. Data Exploration
- Loaded the dataset using Seaborn.
- Explored the data using `head()`, `tail()`, `shape()`, `info()`, and `describe()`.
- Checked column names and data types

### 2. Data Cleaning
- Checked for missing values.
- Calculated the percentage of missing values.
- Filled numerical missing values using median.
- Filled categorical missing values using mode.
- Checked important columns and handled missing records where necessary.

### 3. Visualization Using Matplotlib & Pandas

Practiced creating the following charts using both approaches:

- Line Chart – Average fare over time.
- Bar Chart – Total fare by pickup borough.
- Pie Chart – Distribution of payment methods.
- Histogram – Distribution of taxi trip distances.
- Box Plot – Tip amount distribution by pickup borough.

### 4. Visualization Using Seaborn

Also explored five statistical visualizations:

- Count Plot – Number of trips by pickup borough.
- Scatter Plot – Relationship between distance and fare.
- Heatmap – Correlation between numerical variables.
- Pair Plot – Relationships between distance, fare, tip, and total.
- Violin Plot – Fare distribution by payment method.

## Key Learnings

This assignment gave me an opportunity to practice:

- Exploring and understanding a dataset.
- Handling missing values.\
- Grouping and summarizing data using Pandas.\
- Creating different types of charts using Matplotlib and Pandas.\
- Exploring statistical visualizations using Seaborn.\
- Understanding patterns, distributions, and relationships through charts.\

## Conclusion

This was a good learning experience for me as a beginner in Data Analytics. I got to practice different visualization techniques and understand how each chart helps us look at data from a different perspective.

I'm gradually improving my Python skills through practical assignments, and this project is another step forward in my Data Analytics journey.
